# Information Architecture

## 1. CMS Navigation Structure
The CMS is strictly scoped to the following navigation hierarchy to maintain focus and simplicity:

- **Dashboard**
- **Content**
  - Articles
  - Case Studies
- **Resources**
  - Digital Assets
- **Settings**

*Note: Analytics are NOT a separate top-level navigation item. They are integrated into the Dashboard.*

## 2. Unnecessary Modules
To keep the CMS focused on Bangjeje's core requirements, do NOT create or include the following modules (unless explicitly requested in a future phase):
- Marketing
- Organization
- CRM
- Leads
- Separate Analytics application
- Separate Media Library application

## 3. Dashboard Responsibilities
The Dashboard serves as the central executive overview of the CMS. It will provide:
- Content statistics
- Article statistics
- Case Study statistics
- Digital Asset statistics
- Recent Articles
- Recent Case Studies
- Recent Digital Assets
- Publishing/activity information
- Relevant analytics
- Quick actions

*(Note: The Dashboard UI is not being built during Phase 0. This document solely outlines its architecture and responsibilities.)*
